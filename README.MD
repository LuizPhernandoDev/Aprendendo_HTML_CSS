# 🎨 Aprendendo HTML & CSS

Este repositório atua como um registro do meu desenvolvimento no desenvolvimento web front-end, contendo exercícios práticos, layouts e projetos acadêmicos.

## 🧪 O que este repositório contém?
- **Estruturação Web (HTML5)**: Práticas com tags semânticas, formulários, acessibilidade e SEO básico.
- **Estilização e Layout (CSS3)**: Estudos sobre Flexbox, CSS Grid, responsividade (Media Queries) e animações.
- **Projetos Pessoais**: Criação de páginas de destino (landing pages), portfólios e recriação de interfaces para fixação do aprendizado.

## 🛠️ Tecnologias
- **HTML5**
- **CSS3**
